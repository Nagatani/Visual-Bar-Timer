# ビジュアルバータイマー (Visual Bar Timer)

目盛りで残り時間が直感的に一目でわかる、20分割バー液晶スタイルのタイマーアプリケーションです。

- **Web版**: ライブラリ・フレームワークを一切使用しない **Pure Vanilla HTML/CSS/JS** 実装
- **デスクトップ版**: **Rust + Tauri v2** による軽量ネイティブアプリ（最前面固定・コンパクトバーモード対応）

---

## 🌟 主な特長

1. **20個の目盛り（バー）で残り時間を一目で可視化**
   - **カウントダウン**: 設定時間に応じて20個の目盛りが1つずつ減っていきます。
   - **カウントアップ**: 約5分ごとに目盛りが1つずつ増えていきます（最大99分59秒）。
2. **リピート計測モード（ポモドーロ・テクニック対応）**
   - 作業時間（デフォルト25分）と休憩時間（デフォルト5分）を交互に繰り返すタイマー。
   - 作業と休憩の切り替わりには「ピピピッ」と3回の電子音でお知らせ。
   - 最後の作業時間が終わるとアラームでお知らせ。
3. **消音（MUTE）切り替え**
   - 図書館やオフィスでも安心の消音スイッチ。消音時は液晶画面が点滅して視覚的にお知らせします。
4. **ホワイトテーマ / ブラックテーマ切り替え**
   - ハイコントラストなLCD表示のスキン切り替え（白背景 / 黒背景）。
5. **縦置き / 横置き切り替え**
   - 冷蔵庫やホワイトボードにマグネットで縦貼りする実機のスタイルに対応。
6. **デスクトップアプリ限定機能 (Tauri)**
   - **最前面固定（Always on Top）**: 作業画面の片隅に常に表示。
   - **コンパクトフローティングバー**: 邪魔にならないスリムなバー表示に縮小可能。

## 🚀 使い方・起動方法

### 1. Webアプリとして起動（インストール不要）
ブラウザで直接 `web/index.html` を開くだけですぐに使用できます。

ローカルサーバーで起動する場合:
```bash
npm start
# または
npx serve web -p 3000
```
ブラウザで `http://localhost:3000` にアクセスしてください。

### 2. デスクトップアプリとして起動 (Tauri)
```bash
npm run tauri:dev
```

## ⌨️ キーボードショートカット

| キー | 動作 |
|---|---|
| `Space` | スタート / 一時停止 / アラーム停止 |
| `R` | リセット |
| `M` | モード切替（通常 / リピート） |
| `S` | 消音（MUTE）オン・オフ |
| `1` | +10分 |
| `2` | +1分 |
| `3` | +10秒 |
